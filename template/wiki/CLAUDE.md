This repository is a structured wiki — a collection of interlinked pages organised by category with consistent formatting, cross-references, and auto-generated navigation.

## Directory Layout

- `pages/` — all wiki pages, organised into category subfolders (e.g. `pages/networking/`). Each page is a standalone markdown file.
- `assets/` — images and diagrams referenced by pages. Mirror the category structure (`assets/networking/diagram.png`).
- `SIDEBAR.md` — auto-generated navigation sidebar. Regenerated by `/knowledge-documentation:index-topic`.
- `TOC.md` — auto-generated flat table of contents. Regenerated alongside `SIDEBAR.md`.

## Page Format

Every page must follow:

```markdown
# Page Title

> Brief one-line summary.

**Category:** category-name
**Last updated:** YYYY-MM-DD
**Version:** X.Y.Z

## Overview

Context — what this topic is and why it matters.

## Content

Main body. Use subheadings, tables, fenced code blocks.

## See Also

- [Related Page](../category/related.md)
```

### Format Rules

- Always include the metadata lines directly below the summary blockquote.
- Use relative links for cross-references between pages.
- Reference assets via relative paths from the page location.
- Use ATX-style headers (`#`, `##`, `###`).
- No emojis.

## Workflow

1. `/knowledge-documentation:new-page "Title" --category=networking` — scaffold a page with correct frontmatter.
2. Draft content.
3. `/knowledge-documentation:cross-link` — insert cross-references with related pages.
4. `/knowledge-documentation:index-topic` — regenerate `SIDEBAR.md` and `TOC.md`.
5. `/knowledge-documentation:audit-links` — verify no broken links before committing.
6. `/knowledge-documentation:version-doc <path>` when making substantive revisions.
