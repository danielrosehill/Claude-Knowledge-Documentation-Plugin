# Inclusion Criteria

Edit this file to define what qualifies for inclusion in this resource library.

## Required

- Must be directly relevant to `{{RESOURCE_TOPIC}}`.
- Must have a public, stable URL.
- Must be actively maintained or historically significant.

## Excluded

- Dead links, 404s, repos archived >3 years with no successor.
- Marketing pages with no substance.
- Duplicate or re-uploaded content.

## Notes

- Prefer primary sources over aggregators.
- One entry per distinct resource — if a tool has multiple distributions, pick the canonical one.
